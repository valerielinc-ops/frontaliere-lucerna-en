Full description

As a partner in agriculture, BISON ensures that Swiss food reaches consumers. It is important that IT can be optimally adapted to the needs of the specialist areas.This is exactly where you come into play as an integration specialist / .NET developer Microsoft Azure*! Thanks to your daily work in Sursee, everything is coordinated with the business and optimally aligned for the future.You want to develop modern integration solutions and develop further in the Microsoft and Azure environment? Then you are right with us.

You do that.

  • Development and further development of integration solutions with Azure Integration Services (including Logic Apps, Azure Functions, API Management, Service Bus)
  • Implementation of interfaces and workflows with Azure Logic Apps
  • Development of services and integration components with Azure Functions
  • Develop and deploy APIs via Azure API Management
  • Implementation of messaging and event-based integrations with Azure Service Bus
  • Development of REST APIs and web services with ASP.NET Core and C#
  • Connection of internal and external systems via REST, messaging and other interface technologies
  • Analysis of requirements and development of suitable technical solutions
  • Testing, troubleshooting and continuous improvement of existing integrations
  • Collaboration on architecture, security and DevOps topics around our integration platform
  • Collaboration with internal departments, application teams and external partners

That's what you bring with you.

  • Several years of experience (minimum 3 years) in software development with C# / .NET
  • Experience with Azure Integration Services, such as Azure Service Bus, Azure Functions, Logic Apps or API Management
  • Knowledge of API development (REST) and messaging concepts
  • Experience with structured data formats such as XML or JSON
  • Advantages are: experience in web development (e.g. ASP.NET Core, HTML, JavaScript), Git and CI/CD, Azure DevOps, OAuth 2.0 / OpenID Connect, containers, Kubernetes or other cloud-native technologies, monitoring and application insights
  • Understanding integration concepts and enjoying solving technical relationships in a structured way
  • Self-employed and reliable working methods
  • You have stylish German and good English skills for technical documentation
